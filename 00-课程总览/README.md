# 00 · 课程总览

CS224N / LING 284 / SYMSYS 195N  
Natural Language Processing with Deep Learning · Stanford Winter 2026

## 这门课在讲什么

自然语言处理是信息时代最重要的技术之一：搜索、客服、翻译、医疗记录、政治文本，几乎所有人类交流都会经过语言。2010 年代，端到端神经网络在多数 NLP 任务上取得很高表现，不再依赖任务特定的特征工程。2020 年代则是大语言模型规模化（如 ChatGPT）带来的新范式。

本课同时覆盖：

1. 深度学习 NLP 基础：词向量、RNN、注意力、Transformer
2. 当代方法：预训练、后训练、高效适配、Agent、推理、多语言、多模态、可解释性
3. 动手能力：用 PyTorch 设计、实现、训练、调试自己的模型
