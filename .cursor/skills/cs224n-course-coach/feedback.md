# Feedback 写法

检查作业、中期回顾、或学生问「怎么样了」时用下面结构。对着 `My-Submits/` 里的文件写，不要对着空气写。

```markdown
## Feedback · {A1|A2|A3|A4|提案|中期|终稿|海报|W?}

### 做得对
- …

### 缺什么 / 与 handout 不符
- …

### 概念或实现问题
- …

### 下一步（学生自己做）
1. …
```

要求：

- 「做得对」要具体（函数名、题号、报告小节），不要只写「整体不错」。
- 「缺什么」对照官方 handout 的交付清单。
- 「问题」先讲错因，再给提示；需要公式就写公式。不要贴可直接粘贴的完整标准答案。
- 「下一步」3 条以内，按优先级。写完把 `PROGRESS.md` 里该项改为 `待检查` 或 `已完成`。
